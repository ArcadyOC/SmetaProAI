# Чек-лист проверки сметы

Прогонять перед тем, как показать смету Маше как финальную. Опора — форма и правила из Приложений 2–3 к Общим положениям СН-2012 (см. [[smeta-compiler]]) и структура базы ([[smeta-sn-database]]).

## 1. Соответствие базе

- [ ] Каждый шифр в смете — реальный `full_code` из `data/sn2012_2026.sqlite`, не выдуман и не «похожий».
- [ ] Наименование работ в смете совпадает с `rates.name`/`table_name` (не пересказ своими словами).
- [ ] Единица измерения в смете = `rates.unit` для этой расценки (частая ошибка — спутать «100 м2» и «1 м2», «шт.» и «100 шт.»).
- [ ] Если расценка отмечена как «приблизительная» (аналог, коэфф. 0,2 для демонтажа и т.п.) — это явно помечено в смете, а не выдаётся за точное соответствие.

## 2. Полнота состава работ

- [ ] Сверено с [[smeta-rate-picker]]: учтены не только основные позиции, но и сопутствующие (см. таблицу «что не учтено нормативом» — подъёмная техника, вертикальный транспорт, основные материалы для замены и т.д.), если они реально нужны по заданию.
- [ ] Нет дублей позиций (одна и та же работа не посчитана дважды под разными шифрами).
- [ ] Если использован обходной норматив (демонтаж через монтаж ×0,2, замена аналогом) — обоснование указано прямо в смете.

## 3. Расчёты

- [ ] Для каждой позиции: `Всего на ед. = ЗП + ЭМ + МР + ЗП×0,70 + ЗП×0,10 + ЗПМ×1,08` (или ЗП×0,80 вместо 0,70 — только для дорожной разметки, п.10.2 Общих положений).
- [ ] Итого по позиции = Всего на ед. × Кол-во × Поправочные коэфф. (без коэфф. зимних удорожаний и пересчёта — они не применяются).
- [ ] ЗТР по позиции = ЗТР на ед. × Кол-во.
- [ ] Нет ошибок округления (сверить хотя бы одну позицию вручную по формуле).
- [ ] Итог по смете = корректная сумма всех позиций (плюс материалы, не учтённые нормативом, если были добавлены).

## 4. Формальное оформление

- [ ] Форма сметы соответствует Приложению 2 (шапка: объект, номер, основание, уровень цен на 01.07.2026, сметная стоимость, средства на оплату труда).
- [ ] У каждой позиции есть расшифровка статей (ЗП/ЭМ/в т.ч. ЗПМ/МР/НР от ЗП/НП от ЗП/НР и НП от ЗПМ/ЗТР), а не только итоговая сумма.

## Итог проверки

Формировать краткий отчёт: что проверено, что вызывает сомнение (с указанием позиции), что нужно перепроверить вручную вместе с Машей. Не подтверждать смету как «корректную», если часть позиций не удалось сверить с базой — явно перечислить такие места.

## Ограничения

- Не занижать строгость проверки ради «красивого» результата — если что-то не сходится, писать прямо.
- Не пересчитывать проценты НР/НП по-своему — только фиксированные 70/10, 80/10 (дорожная разметка), 78/30 (от ЗПМ) из п.10 Общих положений.

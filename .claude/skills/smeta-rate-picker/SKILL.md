# Принцип подбора

1. По описанию задания определить главу/сборник в [[smeta-sn-database]] (см. таблицу сборников там же). Кровля → Глава 1, Сборник 7 «Крыши и кровли» (+ Сборник 7 Главы 7 для специальных объектов, п.24 Общих положений). Инженерные сети вне здания → Глава 2. И т.д.
2. Искать расценки: `python scripts/search.py "ключевое слово" --kind rates` (полнотекстовый поиск по `rates_fts`) либо прямой SQL по `rates.name`/`table_name`/`department`. Смотреть на `full_code`, `unit`, `direct_cost`, `work_composition`.
3. Проверить состав работ (`work_composition` или сам PDF по `document_id`/`rel_path`) — расценка должна покрывать реально нужные операции, а не просто похожее название.
4. Если задание описывает и обслуживание, и разовые операции (осмотр → ТО → ремонт → замена) — учитывать все нужные этапы, а не только один.
5. Если в базе нет данных для однозначного выбора — сказать «недостаточно данных для точного подбора», а не подставлять похожую позицию без пометки.

## Общий охват нормативов — что уже включено (п.6, п.14 Общих положений)

В стоимостной норматив, как правило, УЖЕ входит:
- основная операция + вспомогательные и сопутствующие операции;
- выгрузка и перемещение материалов/изделий до рабочей зоны и по фронту работ;
- уборка и перемещение строительного мусора в отведённые места;
- для ремонтных работ (30-е отделы) — перемещение материалов по горизонтали до 80 м;
- для глав 2, 3, 4 — время на доставку бригад до объекта и между объектами в течение смены (для главы 1 это считается отдельно, по согласованию с заказчиком, п.11).

## Что нормативом НЕ учтено — докупать/считать отдельно

Явно из Общих положений (`OP.pdf`), при подборе обязательно проверять и предупреждать:

| Что не учтено | Как считать | Источник |
|---|---|---|
| Подъёмно-транспортная техника, грузовые/грузопассажирские подъёмники для подъёма материалов, их установка/разборка | отдельным расчётом в смете | п.11 |
| Вертикальный транспорт материалов лебёдками | по нормативам таблиц 1.50-3305-1 и 1.50-3305-2 | п.11 |
| Вертикальный транспорт вручную | по таблице 1.50-3305-3, + 10 м пути на каждый метр подъёма, + 8 м на каждый метр спуска (при уклоне <4% добавка не нужна) | п.11 |
| Основные материалы для ремонта/замены (трубы, арматура, провода, кабели, светильники, запчасти оборудования и т.п.) | как правило, отдельной строкой по цене из Главы 21 (`materials.price`) — сверить, не входит ли в норматив; если не входит, но есть в «приложении 2» к сборнику — оттуда | п.20 |
| Возврат материалов от разборки | натуральные показатели и стоимость приведения в годное состояние — не учтены, условия определяют заказчик/подрядчик в договоре | п.16, п.17 |
| Промежуточное складирование (перевалочная база) | отдельным расчётом, если указано в ТЗ заказчика | п.15 |
| Оборачиваемые материалы (опалубка, крепления) | уже учтены с нормальным числом оборотов — доп. считать не нужно | п.12 |

## Если нужного норматива нет в сборнике

- **Демонтаж/разборка** конструктивных элементов без прямого норматива → брать норматив на монтаж/устройство того же элемента из 3-х разделов 30-х отделов соответствующего сборника СН-2012, **без стоимости материалов**, с коэффициентом **0,2** к ЗП и к затратам на эксплуатацию машин (п.22).
- **Антисептирование/антикоррозионная защита/окраска металла** при содержании объектов Главы 5, если норматива нет → брать по Сборнику 13 «Внутренняя отделка» Главы 1 (п.25).
- **Расчистка старой краски** под окраску вновь → норматив `13-3204-1-1/1` (п.25).
- Если и такого обхода нет — честно: «расценка в базе отсутствует, нужно решение по аналогии или отдельная калькуляция», не выдумывать шифр.

## Периодичность работ (п.19)

Норматив, как правило, на **однократное** выполнение, если иная периодичность не указана в самом наименовании. Правило вложенности: в норматив на ежеквартальное ТО уже включены работы ежемесячного; в полугодовое — работы ежеквартального; в годовое — работы полугодового. **Нельзя** самовольно делить норматив на части по времени — если пользователь просит смету «на месяц» при нормативе на квартал, это нужно явно обсудить, а не просто разделить сумму на 3.

## Ограничения

- Никогда не выдумывать шифр расценки — только `full_code` из [[smeta-sn-database]].
- Если однозначного соответствия нет — так и сказать, предложить уточняющие вопросы к заданию.
- Подмена отсутствующей позиции похожей — только с явной пометкой «расценка приблизительная, требует проверки» и обоснованием, почему выбрана именно она.

# Мозговой штурм по созданию программы/бота для составления смет по расценкам СН на 2026 год

## Название проекта

**SmetaProAI**. Telegram-бот: `@SmetaProAI_bot` — хэндл зарегистирован.  ссылка на проект https://github.com/ArcadyOC/SmetaProAI

## Описание идеи

Предполагается создание программы или бота (в Telegram-канале или другой платформе), который будет выступать в роли эксперта по составлению смет на основе сметных расценок (СН) за 2026 год. База СН скачивается с официального сайта и содержит большой объем информации.

Источник актуальной базы СН: https://www.mos.ru/depr/documents/cenovaya-politika/cenoobrazovanie-v-gorodskom-khozyaistve/cenoobrazovanie-v-gorodskom-khozyaistve-2026-god/

## Функционал бота

1. **Экспертность**: Бот должен обладать знаниями о том, как правильно составлять сметы, как устроена база СН, и как с ней корректно работать.
2. **Помощь в подборе расценок**: При поступлении задания (например, «составить смету на ремонт кровли»), бот должен уметь подсказывать, какие расценки лучше подобрать, какие правила применять, какой состав работ должен быть учтен.
3. **Автоматизация**: Цель — минимизировать ручное копание в расценках, предоставив пользователю инструмент для интерактивной помощи в формировании сметы.

## Задачи для разработки

- Изучение структуры базы СН 2026 года.
- Сбор информации о правилах составления смет.
- Разработка логики взаимодействия с ботом для подбора расценок.
- Выбор платформы реализации (Telegram, Max и т.д.).
